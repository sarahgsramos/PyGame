# DORA AVENTUREIRA: RESGATANDO O BOTAS

### Descrição do jogo:
Um jogo de plataforma onde a personagem principal "Dora" precisa atravessar um rio pulando entre troncos para resgatar seu amigo "Botas", desviando de peixes que saltam da água e de raposos que bloqueiam o caminho.

### Instruções do jogo:

Movimentação: Setas esquerda e direita para andar; Seta cima para pular.

Para iniciar o jogo: Aperte a tecla "Espaço" na tela inicial.

Vidas: A Dora começa com 3 vidas.

Formas de perder uma vida: Cair na água ou encostar em um obstáculo (peixe ou raposo).
Ao perder uma vida, a Dora volta para o último tronco seguro. Ao perder todas as vidas, o jogo termina em derrota.

Objetivo: Atravessar todo o rio e encostar no Botas para vencer.

Para iniciar o jogo, execute o arquivo chamado **jogo.py**.
